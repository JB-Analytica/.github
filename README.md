## Open Source

### ⭐ [model2data](https://github.com/JB-Analytica/model2data)

**Turn your data model into realistic, analytics-ready data in seconds.**

`model2data` generates privacy-safe synthetic data and complete dbt project scaffolding directly from a DBML data model.

```text
DBML
  ↓
Schema parsing
  ↓
Synthetic data generation
  ↓
dbt project
  ↓
Analytics-ready dataset
```

Built for **data engineers, analytics engineers and developers** who need realistic data for development, testing and prototyping without relying on production data.

→ [Explore model2data](https://github.com/JB-Analytica/model2data)
